# Политика конфиденциальности PREYDAX Marketplace Intelligence

**Дата последнего обновления: 16 ноября 2026 года**

## 1. Общие положения

Настоящая Политика конфиденциальности описывает принципы обработки и защиты данных при использовании расширения PREYDAX Marketplace Intelligence для браузера Google Chrome.

PREYDAX — инструмент для анализа товаров, цен, ассортимента и рыночных показателей маркетплейсов Wildberries и Ozon.

Мы стремимся обеспечить прозрачность обработки данных и использовать их исключительно для предоставления и улучшения функций расширения.

## 2. Какие данные могут обрабатываться

В зависимости от используемых функций расширение может обрабатывать:

- Информацию о товарах, ценах, ассортименте, рейтингах и других показателях маркетплейсов.
- Настройки пользователя и параметры аналитики.
- Результаты анализа и временные данные, необходимые для работы расширения.
- Информацию, получаемую через подключённые API маркетплейсов, если пользователь использует соответствующие функции.

Объём обрабатываемых данных зависит от доступных функций и действий пользователя.

## 3. Цели использования данных

Данные обрабатываются для следующих целей:

- Предоставление аналитических инструментов Wildberries и Ozon.
- Отображение информации о товарах и рыночных показателях.
- Сохранение пользовательских настроек.
- Формирование результатов анализа.
- Обеспечение стабильной работы и улучшение функций расширения.

## 4. Хранение данных

PREYDAX может использовать локальное хранилище браузера Chrome для сохранения настроек и аналитических данных.

Для работы отдельных функций может применяться обработка данных через внешнюю серверную инфраструктуру. Если такая обработка осуществляется, её условия должны соответствовать настоящей Политике.

## 5. Передача данных третьим лицам

Данные пользователей не должны продаваться или использоваться для рекламного профилирования, определения кредитоспособности либо целей, не связанных с основной функциональностью расширения.

Передача данных техническим поставщикам допускается только в объёме, необходимом для предоставления заявленных функций, с соблюдением применимых требований конфиденциальности.

## 6. Разрешения браузера

Для работы PREYDAX могут использоваться следующие разрешения:

- **storage** — сохранение настроек и состояния расширения.
- **unlimitedStorage** — хранение больших объёмов аналитической информации.
- **alarms** — выполнение запланированных фоновых задач.
- **notifications** — отображение уведомлений пользователю.
- **Доступ к сайтам** — взаимодействие со страницами поддерживаемых маркетплейсов для выполнения аналитических функций.

## 7. Безопасность

Разработчик стремится применять разумные технические и организационные меры для защиты обрабатываемой информации от несанкционированного доступа, изменения и раскрытия.
